# Store

Aplicación de tienda compuesta por un sitio web público, un dashboard administrativo, una API REST y una base de datos SQL Server.

## Estructura

```text
frontend/
  store-web/
  store-dashboard/
  shared/store-ui/
backend/
  Store.Api/
  Store.Application/
  Store.Domain/
  Store.Infrastructure/
database/
```

## Estado actual

El proyecto se encuentra en la Fase 0 de preparación. Las aplicaciones Angular y la solución base de ASP.NET Core están creadas, pero todavía no se han implementado funcionalidades de negocio.

## Versiones base

- Angular CLI: 22.1.6
- Node.js: 24.20.0
- npm: 11.19.0
- .NET SDK: 10.0.303
- SQL Server: objetivo del proyecto, administrado mediante scripts SQL

## Próximas fases

La implementación continuará progresivamente con backend base, base de datos, seguridad, catálogo, inventario, compras, ventas, dashboard, sitio web y reportes.
