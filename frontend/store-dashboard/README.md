# Store Dashboard

Aplicación Angular administrativa privada de Store.

## Desarrollo

Instalar dependencias y levantar el servidor local:

```bash
npm install
npm start
```

La aplicación estará disponible en `http://localhost:4200/`.

## Construcción y pruebas

```bash
npm run build
npm test
```

La aplicación se generó con Angular CLI `22.1.6`, usando standalone components, Angular Router y SCSS.
